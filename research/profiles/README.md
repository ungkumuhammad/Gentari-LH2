# `profiles/` — Licensor & technology-provider profiles

Sourced, one-file-per-provider profiles of the LH2 technology landscape,
maintained by **Zane**. Filename: `<provider>.md` (e.g. `kawasaki.md`,
`linde.md`, `air-liquide.md`).

Each profile carries, with a citation on every figure:

- **Technology & TRL** — liquefaction cycle, carrier/tank tech, terminal &
  vaporiser offering, current maturity.
- **Reference projects** — plants, vessels, terminals delivered or announced.
- **Disclosed performance / specs** — SEC, BOR, capacity, etc. (each cited or
  tagged).
- **Commercial posture** — offering model, disclosure gaps.
- **Cross-links** — to any related data already in the repo (e.g. Kawasaki data
  already lives in `../../data/`; profile it here, don't duplicate the numbers —
  link to the `references.csv` id).

No fabricated numbers — cite or tag everything (see `../AGENT.md` §3).
