# `digests/` — Weekly LH2 news digests

Dated LH2 news digests produced by **Zane**. One file per run:

```
YYYY-MM-DD-lh2-weekly.md
```

- **Cadence:** Monday 07:00 Malaysia Time (Sunday 23:00 UTC), via the scheduled
  trigger. Manual runs are welcome too — same filename convention, tag the run
  as manual in the header.
- **Format:** [`../templates/weekly-digest-template.md`](../templates/weekly-digest-template.md).
- **Scope:** liquid hydrogen only (see `../AGENT.md` §6).
- **Dedup:** each digest reports only what is new or materially updated versus
  earlier digests in this folder.

Every figure in a digest is cited or tagged — no fabricated numbers. Sources are
mirrored into [`../sources/staging.csv`](../sources/staging.csv).
